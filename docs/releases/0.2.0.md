Lumen 0.2.0 adds personal memory and personalization across conversations.

- Automatically remember useful details from normal conversation without asking the model to save them. Memory and automatic saving start enabled and can be switched off independently.
- Skip repeated facts and paraphrases, update existing memories when details change, and honor requests not to save a new detail.
- Use the new Personalization preferences to share your name and profile and to add, review, edit or delete saved memories. Profile fields hide when sharing is switched off while keeping their text.
- Configure personalization and memory in the first-run setup. Choices are saved when setup finishes.
- Follow updated assistant instructions and see guidance about custom instructions affecting tools and memory.
- Try setup or memory with isolated test data using the included development scripts. The app has no test banner.
- Fix occasional clipping in the message composer and code previews after text changes.

Saved memories are stored locally and are sent to the selected Ollama server when enabled. Automatic saving uses an additional model request and requires structured JSON output support. Existing saved off switches are respected. Deleting a chat keeps its saved memories; manage those in Personalization.

Download `Lumen-0.2.0-x86_64.flatpak` and its `.sha256` file. To verify and install from the download folder:

```bash
sha256sum -c Lumen-0.2.0-x86_64.flatpak.sha256
flatpak install --user ./Lumen-0.2.0-x86_64.flatpak
```

Ollama and models are installed separately. Existing chats and settings are preserved when updating.

Validation: 83 automated tests; native setup, personalization, editing, image handling, composer sizing, equations, branding, search/scrolling and full UI smoke checks; packaged verification of both user and system installations, including memory persistence, Python isolation, tools and composer growth/shrink.
